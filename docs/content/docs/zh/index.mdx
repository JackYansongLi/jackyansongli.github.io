## 关于我

我是**宁波东方理工大学**[陈十一](https://faculty.eitech.edu.cn/mech/csy1/main.htm)课题组的副研究员。

在此之前，我共同创立了开源公司[三鲤网络](https://liiistem.cn/) (LIII NETWORK)。我在伊利诺伊大学芝加哥分校 (UIC) 电气与计算机工程系获得博士学位，非常幸运能受教于导师 [韩硕](https://hanshuo.people.uic.edu/site/) 教授。我本科毕业于[南方科技大学](https://www.sustech.edu.cn/)数学系，在此期间得到了[刘鲁川](https://staff.uic.edu.cn/andylcliu/en)教授的大力指导与热情帮助。

以下附上我的个人简历。我非常欢迎与我的专业背景和兴趣相契合的合作机会。如果您对我们的产品或我的研究感兴趣，欢迎随时联系我：[**[个人简历 CV]**](/résumé_yansong.pdf) | [**[联系我：ysli@eitech.edu.cn]**](mailto:ysli@eitech.edu.cn)

## 开源项目贡献

我共同创立了开源公司[三鲤网络](https://liiistem.cn/) (LIII NETWORK)，该公司开发并维护了以下项目：

<ul>
  <li>
    <a href="https://github.com/XmacsLabs/mogan">Mogan STEM</a>（墨干编辑器）：我是 Mogan 的核心维护者之一。这是一款所见即所得的 TeX 风格编辑器，可帮助用户以比 LaTeX 快 10 倍的速度输入数学公式。可以查看“<a href="https://www.youtube.com/watch?v=H46ON2FB30U">A quick tour of TeXmacs</a>”获取 3 分钟快速介绍。
  </li>
  <li>
    <a href="https://github.com/LiiiLabs/goldfish">Goldfish Scheme</a>：我是 <code>Goldfish Scheme</code> 的维护者之一。这是一个基于 <a href="https://ccrma.stanford.edu/software/snd/snd/s7.html"><code>S7 Scheme</code></a> 和 <code>C++</code> 的 Scheme 解释器。该解释器保持了 <code>S7</code> 的高效与简洁，同时大幅提升了对 <code>Microsoft Windows</code> 平台的支持。在 <code>Goldfish Scheme</code> 中，我们实现了 <a href="https://r7rs.org/"><em>R7RS</em></a> 的完整特性，并吸取了 <code>Python</code> 标准库的许多优良特性。<code>Goldfish Scheme</code> 未来将成为 GNU TeXmacs/Mogan 的核心基石。
  </li>
</ul>
