## 学习要点

翘曲通常来自收缩差异，而非单一变量。冷却不均、纤维取向、保压不足和几何不对称都可能叠加。

## 工程检查

- 分开查看冷却、取向和体积收缩对位移的贡献。
- 对关键尺寸定义测量基准与允许变形方向，避免只看总位移。
- 先消除热不平衡和厚度不连续，再考虑补偿模面。
