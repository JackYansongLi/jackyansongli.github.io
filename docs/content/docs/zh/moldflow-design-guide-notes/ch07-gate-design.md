## 学习要点

浇口决定熔体如何进入塑件，也决定保压何时失效。位置、型式和截面必须同时兼顾流动平衡、外观、取件和后续加工。

## 工程检查

- 选择能缩短主流程并引导熔接线远离关键区域的位置。
- 用浇口冻结时间确定有效保压时间，而不是仅按经验设定。
- 检查浇口处剪切、温升和脱浇口痕迹是否满足材料与外观要求。
