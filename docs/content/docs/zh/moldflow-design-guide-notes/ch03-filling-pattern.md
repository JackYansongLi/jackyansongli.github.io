## 学习要点

良好的充填模式让熔体前沿平稳推进，并尽量同步到达末端。明显滞流或绕流会抬高压力，并增加熔接线、困气和外观缺陷的概率。

## 工程检查

- 查看充填时间等值线，定位先满区和最后充填区。
- 让排气、顶出和外观敏感面避开预测的困气与熔接线位置。
- 优先用壁厚、浇口位置或多点进胶平衡流动，而非单纯增加压力。
