## 学习要点

模具设计必须匹配机器能力，包括注射量、压力、锁模力、模板尺寸、顶出行程和温控接口。仿真中的机器边界应与实际设备一致。

## 工程检查

- 校核投影面积对应的锁模力，并保留工艺波动余量。
- 确认螺杆直径、最大射胶量和缓冲量处于稳定工作区。
- 核对热流道、冷却回路和安全互锁的现场接口。
