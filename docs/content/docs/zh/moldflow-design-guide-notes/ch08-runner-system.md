## 学习要点

流道系统的目标是以可控压降把熔体均匀送到各浇口。几何平衡不必然等于热平衡；长短支路、转角和冷却条件都会改变到达状态。

## 工程检查

- 比较各型腔的充填末端时间、压力和熔体温度。
- 将流道直径与料耗、周期和可用压力一起权衡。
- 评估冷流道、热流道与阀针方案对换色、维护和材料停留时间的影响。
