## 学习要点

工艺控制关注实际过程是否稳定地重复，而不只是控制器显示的设定值。应选择能快速反映变化的过程信号和质量指标。

## 工程检查

- 监控峰值压力、切换位置、缓冲量、制件重量和循环时间。
- 为材料更换、停机恢复和模温变化制定重新确认规则。
- 用受控试验识别关键参数，不在量产中同时大幅调整多个变量。
