## 学习要点

一个稳定循环包含塑化、充填、保压、冷却、开模和顶出。任何阶段的波动都可能在后续阶段放大为尺寸或外观偏差。

## 工程检查

- 分别定义速度切换点、保压曲线、冷却终点和背压范围。
- 用制件重量和缓冲量监测充填与保压的一致性。
- 对周期变化建立原因代码，区分材料、设备和模具因素。
