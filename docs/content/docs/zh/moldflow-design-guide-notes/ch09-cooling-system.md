## 学习要点

冷却设计既决定周期，也决定尺寸稳定性。局部热点会延长开模等待时间，并使不均匀收缩转化为翘曲。

## 工程检查

- 以型腔表面温度分布而非单一进水温度评价冷却均匀性。
- 检查水路间距、孔径、流量和雷诺数，避免低效层流。
- 对厚区、深腔和复杂曲面优先评估隔板、喷泉管或随形冷却。
