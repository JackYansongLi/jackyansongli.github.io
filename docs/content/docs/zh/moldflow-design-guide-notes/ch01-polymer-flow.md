## 学习要点

熔体在模腔内并非理想流体：黏度会随温度、剪切速率和压力变化。设计评审时，应把流动长度、壁厚和浇口位置作为一个整体判断。

## 工程检查

- 识别薄壁、长流程和突然缩厚的位置；它们通常控制充填压力。
- 以流动前沿的温度与速度连续性判断风险，而不是只看是否充满。
- 将材料数据、干燥状态和批次差异纳入仿真的不确定性范围。
