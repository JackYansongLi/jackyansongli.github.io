## 附录F：熔体速度估算

以下推导给出了所需线性熔体速度的估计值，该速度使熔体向模具散失的热量与剪切生热在内部产生的热量相平衡。因此，如果保持所建议的速度，塑料熔体在整个充模过程中应保持均匀的熔体温度。

假设采用幂律黏度模型，黏度建模为：

$$\eta = k \dot{\gamma}^{\,n-1}$$ (式 F.1)

其中 $k$ 为"稠度指数"，表征剪切速率为 1 s⁻¹ 时的黏度，$n$ 为幂律指数。对于该黏度模型，速度 $v$ 作为厚度方向位置 $z$ 的函数为：

$$v(z) = 2\left(\frac{1+1/n}{2+1/n}\right)\left\{1-\left(\frac{2z}{H}\right)^{1+\frac{1}{n}}\right\}\overline{v}$$ (式 F.2)

其中 $\overline{v}$ 为我们要求解的平均线性（体积）熔体速度。剪切速率作为厚度方向位置的函数为：

$$\dot{\gamma}(z) = 2\left(2+\frac{1}{n}\right)\left(\frac{2z}{H}\right)^{\frac{1}{n}}\frac{\overline{v}}{H}$$ (式 F.3)

含内部剪切生热的一维稳态热方程为：

$$\frac{d^{2}T}{dz^{2}} + \frac{q(z)}{\kappa} = 0$$ (式 F.4)

由黏性耗散引起的内部生热 $q(z)$ 为：

$$q(z) = \eta\big(\dot{\gamma}(z)\big)\,\dot{\gamma}(z)^{2}$$ (式 F.5)

将上述黏度和剪切速率表达式代入，剪切生热能量 $q$ 作为厚度方向位置的函数为：

$$q(z) = \frac{2^{\,2+\frac{2}{n}}\,k\left(2+\dfrac{1}{n}\right)^{2}\overline{v}^{\,2}\left(\dfrac{z}{H}\right)^{2/n}\left\{2^{\,1+\frac{1}{n}}\left(2+\dfrac{1}{n}\right)\left(\dfrac{z}{H}\right)^{\frac{1}{n}}\overline{v}\Big/H\right\}^{-1+n}}{H^{2}}$$ (式 F.6)

将该剪切生热项代入能量方程并积分一次，得到：

$$\frac{dT(z)}{dz} = -\frac{k(1+2n)\,z\left\{2^{\,1+\frac{1}{n}}\left(2+\dfrac{1}{n}\right)\left(\dfrac{z}{H}\right)^{\frac{1}{n}}\overline{v}\Big/H\right\}^{1+n}}{\left(2+\dfrac{1}{n}\right)(1+2n)\,\kappa} + C_{1}$$ (式 F.7)

其中 $C_1$ 为积分常数。为求得该常数，假设沿厚度方向的温度分布关于中心线对称，因此 dT/dz 等于 0。于是求得系数 $C_1$ 为 0。对式 F.7 再次积分：

$$T(z) = -\frac{kz^{2}\left\{2^{\,1+\frac{1}{n}}\left(2+\dfrac{1}{n}\right)\left(\dfrac{z}{H}\right)^{\frac{1}{n}}\overline{v}\Big/H\right\}^{1+n}}{\left(2+\dfrac{1}{n}\right)\left(3+\dfrac{1}{n}\right)\kappa} + C_{2}$$ (式 F.8)

为求得 $C_2$，假设模壁处温度恒定。令 $T(z=H/2) = T_{\text{wall}}$。求得系数 $C_2$ 为：

$$C_{2} = T_{\text{wall}} + \frac{2^{\,-1+n}H^{2}k\left(\dfrac{\left(2+\dfrac{1}{n}\right)v}{H}\right)^{1+n}}{\left(2+\dfrac{1}{n}\right)\left(3+\dfrac{1}{n}\right)\kappa}$$ (式 F.9)

相应地，沿厚度方向的温度分布为：

$$T(z) = T_{\text{wall}} + \frac{2^{\,-1+n}H^{2}k\left(\left(2+\dfrac{1}{n}\right)v\Big/H\right)^{1+n} - kz^{2}\left\{2^{\,1+\frac{1}{n}}\left(2+\dfrac{1}{n}\right)v\left(\dfrac{z}{H}\right)^{\frac{1}{n}}\Big/H\right\}^{1+n}}{\left(2+\dfrac{1}{n}\right)\left(3+\dfrac{1}{n}\right)\kappa}$$ (式 F.10)

选择线性熔体速度的目标是使充模过程中的体积熔体温度等于熔体温度。平均温度可通过将熔体温度分布从中心线到模壁积分并除以半厚度来求得：

$$\overline{T} = \frac{\displaystyle\int_{0}^{H/2} T(z)\,v(z)\,dz}{\displaystyle\int_{0}^{H/2} v(z)\,dz}$$ (式 F.11)

其计算结果为：

$$\overline{T} = T_{\text{wall}} + \frac{2^{n}Hkn(1+3n)\,\overline{v}\left(\dfrac{1+2n}{Hn}\,\overline{v}\right)^{n}}{\left(2+13n+20n^{2}\right)\kappa}$$ (式 F.12)

令平均温度等于熔体温度并求解线性熔体速度，得到：

$$\overline{v} = \left\{\frac{(1+2n)}{Hn}\left[\frac{2^{-n}(1+4n)(2+5n)\left(T_{\text{melt}}-T_{\text{wall}}\right)\kappa}{Hkn(1+3n)}\right]^{-1/n}\right\}^{-1+\frac{1}{1+n}}$$ (式 F.13)

对于牛顿流体，n 等于 1，且稠度指数 k 等于某一表观黏度 μ，线性熔体速度简化为：

$$\overline{v} = \sqrt{\frac{35\left(T_{\text{melt}}-T_{\text{wall}}\right)\kappa}{24\,\mu}}$$ (式 F.14)

通过检查单位来验证解的正确性是个好习惯。对于牛顿流体：

$$\overline{v} = \left(\frac{([C])\left[\dfrac{W}{mC}\right]}{[Pa\cdot s]}\right)^{\frac{1}{2}} = \left(\frac{\left[\dfrac{W}{m}\right]}{[Pa\cdot s]}\right)^{\frac{1}{2}} = \left(\frac{\left[\dfrac{N\cdot m}{s\cdot m}\right]}{\left[\dfrac{N}{m^{2}}\,s\right]}\right)^{\frac{1}{2}} = \left(\left[\frac{m^{2}}{s^{2}}\right]\right)^{\frac{1}{2}} = \left[\frac{m}{s}\right]$$ (式 F.15)

看起来速度似乎与壁厚无关，但壁厚的作用通过剪切速率的影响体现出来。当用牛顿模型计算式 F.14 时，需要采用迭代方法，以确保表观剪切速率和黏度与预测的速度相匹配。使用指南及示例参见 5.5.1 节。

许多聚合物的幂律指数 n 约为 1/3。对于这种情况，最优速度为：

$$\overline{v} = 3.81\sqrt[4]{\frac{\left(T_{\text{melt}}-T_{\text{wall}}\right)^{3}\kappa^{3}}{H^{2}k^{3}}}$$ (式 F.16)

可以看出，速度对熔体与模壁温度之差、热导率和稠度指数更为敏感，因为这些项在式 F.16 中以 3/4 次幂出现，而不是式 F.14 中的 1/2 次幂。对于剪切敏感材料，这一特性会进一步加剧：当幂律指数 n 趋近于 0 时，(∆T × κ/k) 的指数趋近于 1。
